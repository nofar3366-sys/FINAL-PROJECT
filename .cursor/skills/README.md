# Project Cursor Skills

These project-scoped Cursor skills guide repository work in the IDE:

- `fitness-studio-course-compliance` checks architecture, refactors, and course
  rubric alignment against the implemented system and `final2026.pdf`.
- `fitness-studio-defense-prep` prepares code-grounded oral defense questions
  and answers for the course presentation.

They are IDE workflow instructions, not Flask runtime tools. The allow-listed
Python tools used by the running application remain in `skills/`.
